# Engineering Interview Sandbox

Welcome. This repository contains a micro-version of our production stack: a Vue 3 frontend and a Django REST Framework backend backed by PostgreSQL. 

## 🚀 Getting Started

Open a split terminal in VS Code and run the following to start the application.

### Terminal 1: Backend (Django)
bash
cd backend
source venv/bin/activate
python manage.py runserver 0.0.0.0:8000


### Terminal 2: Frontend (Vue.js)
bash
cd frontend
npm run dev
